# M0: feasibility gate

Source: the project plan, its M0 milestone and its engine and motor sections. Written 2026-10-01, before the 30-trial runs. The thresholds (r ≥ 0.9, 0.25× real time) come from the project plan and predate all code. This file was written after the engine had already been debugged against the same sugar scenario on one and two trials, so criterion 2 is a test on the scenario the engine was tuned to match, not on unseen input.

All experiment output goes to `sessions/m0/` (gitignored). The report is `docs/M0_REPORT.md`.

## Criteria

### 1. Data pipeline works from a clean clone

```bash
rm -rf data && uv run python scripts/fetch_data.py && uv run python scripts/build_derived.py
```

Pass: both exit 0; every file matches its sha256 pin in `config/data_sources.yaml`; every group in `config/circuits.yaml` resolves inside its `expect` range.

### 2. The engine reproduces the reference sugar → MN9 result

Reference: the published model (`model.py`, Brian2) run locally on v783, because its published output is for v630. Protocol is the reference tutorial's: its sugar GRN list (the 20 of 21 IDs that still exist in v783) driven as Poisson input at 150 Hz, 1 s per trial, 30 trials.

```bash
uv run python scripts/m0_reference.py --trials 30
uv run python scripts/m0_validate.py sugar          # our engine, seeds 0..29, dt 0.1 ms, CPU
```

Compared quantity: each neuron's firing rate averaged over the 30 trials, over the union of neurons active in either model.

Pass: Pearson r ≥ 0.9, and MN9 fires in both. Also reported, with no threshold: number of active neurons in each, total spikes in each, MN9 rate in each, r over non-input neurons only (the inputs fire at the driven rate in both by construction, so they inflate r).

### 3. Benchmark

```bash
uv run python scripts/m0_validate.py benchmark
```

Brain-seconds per wall-second for {CPU, MPS} × {0.1 ms, 0.5 ms}, same sugar scenario, 1 s of brain time after a warm-up. No pass threshold; the the project plan target for live mode is ≥ 0.25×.

### 4. Fast time step

```bash
uv run python scripts/m0_validate.py fastdt
```

Pass (accept 0.5 ms as an option): Pearson r ≥ 0.9 between 0.5 ms and 0.1 ms mean rates, same protocol and seeds as criterion 2. Otherwise 0.5 ms is rejected and the report says so.

### 5. Reachability probe

```bash
uv run python scripts/m0_validate.py reach
```

Each input group (odor A PNs, odor B PNs, sugar GRNs, bitter GRNs, LC4, LPLC2, PPL1, PAM) driven alone at 150 Hz for 1 s, seeds 0..4. Reported: mean rate of each output group (DNa02 left and right, DNp09, MDN, DNp01, MN9), plus MBON mean rate and the fraction of Kenyon cells active. A no-input run is the baseline.

Extra rows: odor A PNs of the left hemisphere only, and of the right only, to test whether a one-sided odor produces a left/right difference in DNa02.

### 5b. Dose-response (exploratory)

Added after seeing criterion 5's results, so it has no pass condition and cannot count as a test. It asks whether a calmer operating point exists below 150 Hz.

```bash
uv run python scripts/m0_validate.py dose
```

Odor A PNs, odor B PNs and sugar GRNs, each alone at 5, 10, 20, 40, 80 and 150 Hz, 1 s, seeds 0..1. Reported per rate: total spikes, active neurons, fraction of Kenyon cells active, MBON rate, MN9 rate, and how many Kenyon cells odor A and odor B share (Jaccard index, seed 0).

### 5c. What calms the mushroom body (exploratory)

Added while 5b was still running, after its first rows showed the mushroom body igniting at 5 Hz. No pass condition. It asks which documented change, if any, gives a sparse, odor-specific Kenyon cell code. Nothing here changes the shipped model.

```bash
uv run python scripts/m0_validate.py ablate
```

Versions of the connectome: unmodified; Kenyon cell to Kenyon cell connections silenced; that plus all output of the dopamine neurons (PPL1, PAM) silenced. After the first run showed those were not enough, two more were added: the same plus the output of the two DPM neurons silenced, and dopamine and DPM output silenced with Kenyon cell to Kenyon cell connections left intact. A class breakdown of the ignited state then showed nearly every undriven projection neuron firing, so a last pair was added: every connection onto the projection neurons silenced (projection neurons become pure inputs), alone and with dopamine output silenced. In each: odor A PNs, odor B PNs and PPL1, each alone at 150 Hz, 1 s, seeds 0..1. Reported: total spikes, fraction of Kenyon cells active and their mean rate, MBON rate, DNa02 left and right, Kenyon cells shared by the two odors, and the tutorial sugar run (seed 0) to check the validated result is untouched.

### 6. Decisions

Decision rules, fixed now:

- **Premotor bridge needed** if a one-sided odor does not move DNa02: the left-minus-right DNa02 rate difference is under 1 Hz, or its sign is not consistent across the five seeds for both the left-only and right-only rows.
- **Pruned subgraph (or other speed-up) needed for live mode** if the best device at the accepted time step is below 0.25× real time.
